# history-detailize 연계 테스트

> **범위**: 이번 변경 사항만 — promptStyle 전송, 이력 카드 신규 필드 표시
> **사전 조건**: 백엔드(8080) + 프론트엔드(3000) 실행 중, 로그인 완료

---

## STEP 1. 상품 프롬프트 생성 — promptStyle 전송 확인

**화면**: `/prompt/new` → `상품 사진 프롬프트` 탭

- [ ] 카테고리 세분류(DCS)까지 선택
- [ ] `NanaBanana 프롬프트` 버튼 클릭 후 생성 완료
  - Network 탭: `POST /api/prompts/goods` 요청 바디에 `"promptStyle": "NANO_BANANA"` 포함 확인
  - 결과 카드 헤더에 `NanaBanana` 뱃지 표시 확인
- [ ] `MidJourney 프롬프트` 버튼 클릭 후 생성 완료
  - Network 탭: 요청 바디에 `"promptStyle": "MID_JOURNEY"` 포함 확인
  - 결과 카드 헤더에 `MidJourney` 뱃지 표시 확인

---

## STEP 2. 이력 화면 — PRODUCT 카드 신규 필드 확인

**화면**: `/prompt/history`

> STEP 1에서 방금 생성한 이력 기준으로 확인

- [ ] 카드 헤더에 `NanaBanana` / `MidJourney` **스타일 뱃지** 표시 확인
- [ ] `카테고리` 경로 텍스트 표시 확인 (예: `식품 > 건강식품 > 약재 > 인삼`)
  - ID 숫자가 아닌 **한글 이름** 으로 표시되는지 확인
- [ ] 태그 선택 후 생성한 이력: `태그` 항목이 **칩** 형태로 표시 확인
- [ ] 태그 미선택 후 생성한 이력: `태그` 영역이 아예 표시되지 않는지 확인

---

## STEP 3. 이력 화면 — PERSON 카드 신규 필드 확인

**화면**: `/prompt/new` → `인물 사진 프롬프트` 탭에서 먼저 생성

- [ ] 옵션 선택 + `생성 목적` / `추가 지시 사항` 입력 후 생성
- [ ] `/prompt/history` 에서 해당 이력 카드 확인
  - [ ] `선택 옵션` 칩 목록 표시 확인
  - [ ] `생성 목적` 텍스트 표시 확인
  - [ ] `추가 지시` 텍스트 표시 확인
  - [ ] PERSON 카드에 `카테고리`, `태그` 영역이 **표시되지 않는지** 확인
